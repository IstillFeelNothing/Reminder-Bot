# reminder_bot

Telegram-бот для нагадувань: Python, aiogram, aiosqlite.
- Вимоги: @REQUIREMENTS.md
- Архітектура й межі модулів: @ARCHITECTURE.md — дотримуйся її суворо
  (domain/ і services/ не імпортують aiogram чи aiosqlite)
- Тести: pytest; сервіси тестуються через in-memory фейки протоколів

## Делегування
- Прочитати/проаналізувати багато коду чи логів → code-analyst
- Простий пошук (де визначено функцію, які файли містять X) → Explore
- Чітко описана рутинна задача → codex-worker
- Після кожної значної зміни → codex-worker робить рев'ю диффу
- Коміти та гілки → git-ops
- Архітектуру, неоднозначні рішення й складний дебаг роби сам
- Дрібні правки (1–3 файли) роби сам, без делегування
- Результат від інших моделей завжди перевіряй тестами

## Git
- Кожна нова задача — окрема гілка: feat/<назва> або fix/<назва>
- Перед комітом: тести проходять + codex-worker робить рев'ю диффу
- Коміти та гілки → git-ops
- Push і PR — лише після мого підтвердження
- Коміти й PR — без Co-Authored-By та будь-яких згадок Claude/AI; автор — з git config
- Для аналізу довгої історії (git log, blame по великих файлах) → code-analyst
